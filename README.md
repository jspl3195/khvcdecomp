# khvcdemop
Decompilation project for KH V-CAST.

This repository does not contain any game assets. This repository will contain only a decopilation of the assembly code for KH V-CAST. The code is not tested against the BREW SDK nor recompiled to machine code. The decompilation was carried over via [Ghidra](https://github.com/nationalsecurityagency/ghidra) and AI tools.

This work was possible thanks to the work from [khvcemu](https://github.com/khrecast/khvcemu).
